WoA Rescue Kit

For the ASUS ProArt PZ13 (Snapdragon / ARM64) tablet when its internal SSD shows up as “no disk” in Windows Setup, in diskpart, in the ASUS recovery USB and in ASUS Cloud Recovery — even though the BIOS clearly shows the drive and its size.

Full guide: open PZ13-Complete-Guide.html for the step-by-step fix, what a backup saves, the EFI partition explained, the complete PZ13 partition table, advice for other Snapdragon devices, and troubleshooting.

What is wrong (in plain words)

These Snapdragon tablets have a special rule built into Windows. On the internal drive, Windows looks at the partitions. The PZ13's SSD shipped holding only Qualcomm firmware partitions and no normal Windows partition. When Windows sees a drive like that on a Qualcomm machine, it deliberately hides the whole drive and refuses to let any Windows tool write to it. That is why every installer says “no disk”.

Because Windows itself does the hiding, the fix cannot be done from inside Windows. It has to be done earlier, from the firmware (UEFI), before Windows loads — and with Secure Boot turned off.

How this kit fixes it

Two USB sticks:

Stick 1 — gptfix A tiny UEFI tool. It adds the four normal Windows partitions (EFI, MSR, Windows, Recovery) into the free space, while keeping all 11 Qualcomm firmware partitions exactly as they are. Once one normal partition exists, Windows stops hiding the drive.
Stick 2 — WinPE installer A mini-Windows that boots, un-hides and formats the drive, then installs Windows automatically and reboots.

This procedure was tested on a real PZ13 on 7 November 2026 and completed a clean Windows install successfully.

Step 1 — Build the two sticks (on any Windows PC)

  1. Plug in the first USB stick (any size, even 1 GB).
  2. Right-click Setup-RescueKit.ps1 → Run with PowerShell. Approve the Administrator prompt.
  3. Follow the questions. It lists only USB drives; you pick one and type ERASE to confirm. Nothing is touched until you do.
  4. When asked, plug in and pick the second stick (16 GB or larger) for the installer. The big copy takes a few minutes.
Each stick you pick is completely erased. Unplug any USB drives you want to keep before you start.

Step 2 — Fix, install, back up or restore (on the PZ13 tablet)

  1. Turn the tablet off. Tap F2 at the ASUS logo to open BIOS/Setup.
  2. Set Secure Boot = OFF. Save and exit.
  3. Only if the SSD shows as empty or hidden (every tool says “no disk”): plug in Stick 1 (gptfix) only, boot from it (F2 → boot menu → the USB), type YES, Enter; when it says “DONE: verified” press Enter to restart.
    If it says “STOPPED”, nothing was written — take a photo and get help. If your disk is already visible, skip this step.
  4. Tap F2, set Secure Boot = ON, save and exit.
  5. Plug in Stick 2 (WinPE) and boot from it. When it says “Type I and press Enter to INSTALL WINDOWS…”, type I and press Enter — the rescue menu opens:

Backing up the disk

Bring a second portable drive (another USB stick or an external drive, formatted exFAT or NTFS) with enough free space. Boot Stick 2, choose [2], pick that drive, then choose:

  • Full system image — your whole Windows (apps, settings, files) plus the boot and firmware partitions. The Windows part is saved compressed, so the backup is about the size of your used space, not the whole disk. Lets you return the laptop to exactly this state.
  • Boot + firmware only — just the partition table and the small firmware/EFI/Recovery partitions (about 2 GB). Small insurance that restores a bootable structure; Windows is then re-installed clean.

Each backup is a folder named pz13-image-<number> on the drive. Keep the whole folder.

Restoring the disk (from a non-boot state)

  1. If the SSD was wiped so completely that it shows as empty or hidden, run Stick 1 (gptfix) first (Secure Boot OFF), as in Step 2.3.
  2. Boot Stick 2, choose [3], plug in the drive that holds your pz13-image-… folder, pick it from the list, and type RESTORE when asked.
  3. It writes the partition table and partitions back. If the backup was a full image, it also re-applies your Windows and fixes the boot files, then restarts. Your laptop is back.

The gptfix tool is safe to run twice — if the partitions are already there it says so and changes nothing. A copy of the SSD's original partition table is kept in 2-winpe-stick\boot\woa-backup\.

A lightweight backup / restore stick (no install image)

If you only want Back up, Restore and Rescue tools — not a clean install — you don't need the 16 GB Stick 2. Any 2 GB or larger stick will do:

  1. Format the stick as FAT32 (right-click the stick → Format → FAT32 → Start). It is erased, so save anything on it first.
  2. Open 2-winpe-stick\boot\ in this folder.
  3. Select everything inside (Ctrl+A) and copy it to the top level of the stick — so the stick ends up with EFI, sources, woa-install.exe, woa-menu.cmd and woa-rescue.tag at its root.

Boot it on the PZ13 (Secure Boot can stay on) and use [2] / [3], with a second drive plugged in to hold or read the backup. A clean install still needs the full Stick 2, because the Windows image lives on its data partition.

Do not just copy a single .iso file onto a stick, and do not use a bare boot-only ISO: WinPE looks for woa-rescue.tag and woa-install.exe at the stick's root, and if they aren't there the backup and restore tools show no drives. Always copy the contents of 2-winpe-stick\boot\.
